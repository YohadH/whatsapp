# Runbook — connect your local Claude to HeyIL (production) and watch it work

Goal: get your local Claude answering real WhatsApp messages on **www.heyil.co.il**,
end to end. ~10 minutes.

> Prereqs: Node 20+, an **Anthropic API key** (console.anthropic.com), and the new
> code deployed to prod (the "מוח תגובות מותאם" panel must exist in Settings → מנוע
> הבינה — if it's missing, the 6 commits aren't deployed yet).

---

## A. Reply provider — the app answers customers with *your* Claude

### 1. Set up the local agent
```bash
cd examples/local-agent
npm install
cp .env.example .env
```
Edit `.env`:
```
ANTHROPIC_API_KEY=sk-ant-...          # your key — this is what powers the replies
HEYIL_SECRET=pick-any-long-random-string   # you'll paste the SAME value into HeyIL
PORT=8787
```

### 2. Run it + expose it over HTTPS
```bash
node reply-server.mjs
# in a second terminal:
cloudflared tunnel --url http://localhost:8787
```
Cloudflared prints a URL like `https://random-words.trycloudflare.com`.
**Your endpoint is that URL + `/reply`**, e.g.
`https://random-words.trycloudflare.com/reply`.

### 3. Wire it into HeyIL (www.heyil.co.il)
Settings → **מנוע הבינה → מוח תגובות מותאם**:
- **כתובת ה-endpoint**: paste the tunnel URL **+ `/reply`** ← NOT an email/domain, the full https URL.
- **סוד לחתימה**: the exact `HEYIL_SECRET` from your `.env`.
- **מתי להתייעץ**: **"בכל הודעה"** while testing (so it fires on every message; switch to
  "רק כשהבוט לא מספיק" later).
- Check **הפעלת סוכן חיצוני** → **שמירה**.

### 4. Prove the connection
Click **שליחת בדיקה**. Success looks like:
`✓ הסוכן החזיר תשובה תוך 1200ms: "…"` — that reply was generated by **your** Claude.
Your `reply-server` terminal will also show the incoming request.

### 5. See it answer a real customer
- **Simulator:** Settings → **בדיקת הסוכן** → type a question → the reply comes from your
  local Claude (watch your terminal light up).
- **Real WhatsApp:** message the connected number → the reply lands on the phone and the
  thread appears in **שיחות** (agent messages labeled ✨ סוכן AI).

**If it's down:** if your laptop/tunnel is off, HeyIL falls back to a human hand-off —
customers are never stuck. That's the safety net.

## B. Ops agent — you drive HeyIL in plain language with *your* Claude

### 1. Create a scoped API key
HeyIL → Settings → **מפתחות API** → **+ יצירת מפתח** → check **קריאה** (and **שליחת הודעות**
if you want it to send). Copy the key (shown once).

### 2. Configure + run
In `examples/local-agent/.env`:
```
HEYIL_API_KEY=heyil_sk_...
HEYIL_BASE_URL=https://www.heyil.co.il
```
```bash
node ops-agent.mjs "כמה לידים ממתינים לנציג? סכם אותם"
node ops-agent.mjs "שלח ל-972501234567: התור שלך אושר למחר ב-10:00"
```
You'll see it call the API (`→ list_leads …`) and answer in your terminal; any message it
sends appears in **שיחות**.

## Security checklist (do these)
- **Always set `HEYIL_SECRET`** — without it, anyone who finds the tunnel URL can POST to your agent.
- Give each **API key the minimum scopes**; **revoke** any key that leaks.
- Only tunnel port **8787**, nothing else. Prefer a named cloudflared tunnel for anything lasting.
- Remember: prod and local currently **share one database** — a local mistake touches prod data.

## Troubleshooting
| Symptom | Fix |
|---|---|
| test: "לא הוגדרה כתובת" | The endpoint field is empty/invalid — paste the full `https://…/reply` URL and Save. |
| test: "endpoint הגיב אך לא החזיר reply" | Your server returned non-JSON or no `reply` — check `reply-server` logs. |
| test: timeout / unreachable | Tunnel not running, or wrong URL. Re-check `cloudflared` output. |
| test: bad signature (401) | `HEYIL_SECRET` in HeyIL ≠ the one in your `.env`. |
| Ops agent 401 | Bad/expired API key. | 
| Ops agent 403 | Key is missing the scope for that action (e.g. `write:messaging`). |
